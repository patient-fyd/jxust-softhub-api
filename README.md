# 江西应用科技学院软件协会官网后端API服务

## 项目简介

本项目是江西应用科技学院软件协会官网和后台管理系统的后端API服务，基于GoFrameV2框架开发。主要提供新闻管理、会员管理、活动管理、文件管理等功能的接口服务。

## 技术栈

- **开发语言**：Go v1.18+
- **框架**：GoFrame v2.x
- **数据库**：MySQL 5.7+
- **缓存**：Redis
- **鉴权**：JWT + RBAC 权限模型
- **ORM**：GoFrame ORM
- **API风格**：RESTful
- **日志系统**：GoFrame 自带 g.Log + 业务审计日志

## 评论功能详细说明

评论功能支持对帖子内容进行评论交流，支持以下主要功能：

### 评论列表查询

可根据内容类型和ID查询对应的评论列表，支持分页查询。评论按时间倒序排列，同时返回评论的点赞数量和当前用户是否已点赞信息。

**接口路径**: `/api/comment/v1/list`  
**请求方式**: GET

### 发表评论

登录用户可对帖子发表评论，系统会自动关联评论者信息，并更新帖子的评论计数。

**接口路径**: `/api/comment/v1/create`  
**请求方式**: POST

### 删除评论

评论作者和管理员可以删除评论，删除评论时会同步清理评论相关的点赞记录，并更新帖子的评论数量。

**接口路径**: `/api/comment/v1/delete`  
**请求方式**: POST

### 评论权限控制

- 游客可查看评论，但不能发表和删除评论
- 登录用户可发表评论和删除自己的评论
- 管理员可删除任何评论

### 相关数据库表

- **comments表**: 存储评论信息
- **likes表**: 存储点赞信息，支持对评论点赞

## 点赞功能详细说明

点赞功能支持对帖子和评论进行点赞，具有以下特性：

### 点赞/取消点赞

用户可以对帖子和评论进行点赞或取消点赞，系统会自动更新目标的点赞数量。

**接口路径**: `/api/like/v1/toggle`  
**请求方式**: POST

### 点赞权限控制

- 只有登录用户才能进行点赞操作
- 用户可以查看帖子和评论的点赞数量
- 系统会记录用户的点赞状态，每个用户对同一目标只能点赞一次

### 相关数据库表

- **likes表**: 存储用户点赞记录，包含用户ID、目标ID、目标类型、创建时间等信息
- **posts表和comments表**: 包含点赞计数字段，实时反映点赞数量

## 关注功能详细说明

关注功能支持用户之间和用户对圈子的关注关系管理，具有以下特性：

### 关注/取消关注

用户可以关注其他用户或圈子，也可以取消关注关系。系统会自动更新被关注对象的粉丝数量和用户的关注数量。

**接口路径**: `/api/follow/v1/toggle`  
**请求方式**: POST

### 获取关注列表

获取指定用户关注的用户或圈子列表，支持分页查询。

**接口路径**: `/api/follow/v1/following/list`  
**请求方式**: GET

### 获取粉丝列表

获取指定用户的粉丝列表，支持分页查询。

**接口路径**: `/api/follow/v1/follower/list`  
**请求方式**: GET

### 关注权限控制

- 只有登录用户才能进行关注操作
- 用户不能关注自己
- 系统会记录关注状态，支持识别互相关注的用户

### 相关数据库表

- **follows表**: 存储用户关注记录，包含用户ID、被关注对象ID、关注类型、创建时间等信息
- **users表**: 包含粉丝数量(followerCount)和关注数量(followingCount)字段，由触发器自动维护
- **circles表**: 包含关注者数量(followerCount)字段

## 圈子功能详细说明

圈子功能支持用户加入不同兴趣领域的社区圈子，进行交流互动，具有以下特性：

### 圈子列表查询

支持获取系统中的圈子列表，可根据关键词搜索、排序规则（最新/最热）等条件筛选，支持分页查询。

**接口路径**: `/api/circle/v1/list`  
**请求方式**: GET  
**查询参数**:
- page: 页码
- size: 每页条数
- keyword: 搜索关键词
- userId: 用户ID（查询该用户关注的圈子）
- orderBy: 排序方式（new: 最新, hot: 最热）

### 圈子详情

获取特定圈子的详细信息，包括圈子名称、描述、成员数量、帖子数量、创建者信息等。

**接口路径**: `/api/circle/v1/detail`  
**请求方式**: GET  
**查询参数**:
- circleId: 圈子ID

### 关注/取消关注圈子

用户可以关注感兴趣的圈子或取消关注，系统会自动更新圈子的成员数量。

**接口路径**: `/api/circle/v1/join`  
**请求方式**: POST  
**请求参数**:
- circleId: 圈子ID

### 圈子权限控制

- 游客可以浏览圈子列表和详情，但不能关注圈子
- 登录用户可以关注/取消关注圈子
- 管理员可以创建官方圈子和管理圈子内容

### 相关数据库表

- **circles表**: 存储圈子基本信息
- **follows表**: 存储用户关注圈子的记录（followType=2）
- **posts表**: 包含circleId字段，用于关联帖子与圈子

更多技术实现细节请参考 [社交功能设计文档](docs/social_features.md)。

## 技术博客功能详细说明

技术博客功能支持用户分享技术文章、经验心得，具有以下特性：

### 博客列表查询

支持获取博客列表，可根据分类、标签、关键词、作者等条件进行筛选，支持分页查询。还可筛选推荐博客和按发布状态筛选。

**接口路径**: `/api/blog/v1/blog/list`  
**请求方式**: GET  
**查询参数**:
- page: 页码，默认1
- size: 每页条数，默认10
- category: 博客分类
- tag: 博客标签
- keyword: 搜索关键词
- authorId: 作者ID
- status: 状态(0-草稿，1-发布，2-下架)，默认1
- isRecommend: 是否推荐(0-全部，1-仅推荐)，默认0

### 博客详情

获取博客详细内容，包括博客正文、作者信息、分类标签、浏览数、点赞数、评论数等信息。

**接口路径**: `/api/blog/v1/blog/detail`  
**请求方式**: GET  
**查询参数**:
- blogId: 博客ID

### 博客创建与编辑

支持创建博客草稿或直接发布博客，支持后续编辑更新。博客内容支持Markdown格式，可上传封面图片，设置分类和标签。

**创建接口**: `/api/blog/v1/blog/create`  
**更新接口**: `/api/blog/v1/blog/update`  
**请求方式**: POST  

### 博客评论功能

支持对博客进行评论和回复，评论支持分页查询和树形结构。

**评论列表**: `/api/blog/v1/blog/comment/list`  
**发表评论**: `/api/blog/v1/blog/comment/create`  
**删除评论**: `/api/blog/v1/blog/comment/delete`  

### 博客点赞功能

支持对博客进行点赞和取消点赞操作。

**点赞接口**: `/api/blog/v1/blog/like`  
**取消点赞**: `/api/blog/v1/blog/unlike`  

### 博客分类和标签管理

支持获取系统中所有博客分类和标签列表，方便用户按分类浏览和搜索。

**分类列表**: `/api/blog/v1/blog/category/list`  
**标签列表**: `/api/blog/v1/blog/tag/list`  

### 博客权限控制

- 游客可以浏览博客列表和详情
- 登录用户可以发布、编辑自己的博客和进行评论
- 只有博客作者和管理员可以编辑、删除博客
- 只有管理员可以设置博客推荐状态

### 相关数据库表

- **blogs表**: 存储博客基本信息
- **blog_comments表**: 存储博客评论
- **blog_likes表**: 存储博客点赞记录

## 开发指南

### 环境要求

- Go 1.18+
- MySQL 5.7+
- Redis

### 初始化数据库

```bash
# 执行SQL脚本
mysql -uroot -p'your_password' < manifest/sql/jxust_softhub.sql
```

### 安装依赖

```bash
go mod tidy
```

### 运行项目

```bash
# 开发环境
make run

# 生产环境
GF_GCFG_FILE=config.prod.yaml ./jxust-softhub-api-api
```

### 代码生成

```bash
# 生成数据访问层代码
make dao

# 生成控制器代码
make ctrl

# 生成服务接口代码
make service
```
