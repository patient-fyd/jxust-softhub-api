# 变更日志

## [1.0.1] - 2025-04-10

### 新增

- 圈子模块功能增强
  - 添加了关注/取消关注圈子的功能 (`/api/circle/v1/join`)
  - 实现了圈子关注状态的双向切换
  - 支持圈子成员数量的实时统计更新

- 社交功能文档
  - 创建了社交功能设计文档 (`docs/social_features.md`)
  - 更新README，添加了圈子功能的详细说明

### 优化

- 模型结构优化
  - 添加了 `CircleJoinInput` 和 `CircleJoinOutput` 数据模型
  - 优化圈子列表和详情接口返回的关注状态信息

- 代码结构优化
  - 实现了 `ICircleV1` 接口的 `Join` 方法
  - 统一错误处理和响应格式
